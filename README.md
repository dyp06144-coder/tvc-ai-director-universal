# TVC AI Director · 通用中文版

一份独立的广告导演技能，将需求诊断、选题、创意提报、导演阐述、制作前会议（PPM）、分镜、图像/视频提示词、制作统筹、剪辑、客户审片组织成可交接的工作流。

正文与模板为中文，实际项目仍按用户语言执行。技能不依赖Lumina、特定模型、画布、原生弹窗或专用编辑器，也不自带媒体工具、素材、API凭据或后台执行服务。

## 快速开始

将完整 `tvc-ai-director-universal` 文件夹交给支持目录技能的宿主；入口是 [SKILL.md](SKILL.md)。

> 使用 tvc-ai-director-universal，为一只无字陶瓷杯做15秒16:9广告方案。受众是职场新人，网页投放，暖色克制风格，不用真人、不承担电商转化、不做功效声明。主题已定为“午后放下手机喝一口水”，口号是“给自己一刻”。只交付创意提案、导演阐述、完整时间码分镜和逐镜提示词，不生成媒体。

需求稀疏时，技能会先确认画幅等影响交付的信息；方向已给时不会再开选题问卷。没有媒体工具时仍可完成所需文字和表格，不会宣称已生成成片。

## 接入方式

| 宿主 | 方式 |
|---|---|
| Codex | 将完整目录放入项目 `.agents/skills/` 或用户 `~/.agents/skills/`，使用自然语言或 `$tvc-ai-director-universal` 指定 |
| Claude Code | 将完整目录放入项目 `.claude/skills/` 或用户 `~/.claude/skills/`，使用自然语言或 `/tvc-ai-director-universal` 调用 |
| 豆包及其他知识库/提示词Agent | 使用 [通用入口](agents/universal-prompt.md)，将主文件与所需参考提供给该Agent可读取的知识来源 |
| 画布Agent | 按宿主支持的指令/多文件入口接入，继续映射真实节点、交互、生成、检查与保存工具 |
| 自建API编排器 | 提供主入口及按需文件读取，将宿主真实工具映射到逻辑能力；不要把逻辑标签直接当成API字段 |

具体导入界面、工具和权限由各产品提供，不宣称所有豆包或Claude界面均支持原生ZIP技能导入。不能读取目录的平台可粘贴主入口及当前需要的参考内容；不要把未加载的资料冒称已读取。

本包只导出，不会自动安装到全局目录或上传到GitHub。

## 能力边界与验证

本包提供调度方法与广告制作知识，不会因接入语言模型就自动获得图片、语音、视频或剪辑能力。方案、实际工具执行、技术检查和内容批准分开记录；有声视频、可编辑工程与最终导出均需真实工具和验收。

已做的验证范围见包内 `package-manifest.json`。文字与调度场景验证不等于在所有Agent产品和付费媒体接口上实际跑完整条制作链。
