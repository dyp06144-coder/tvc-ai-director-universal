# TVC 广告制作九阶段工作流

只展开用户当前请求的阶段。英文阶段代码可作内部路由标签，不是工具名称。各阶段的文字草案可在同一请求内连续完成；进入实际媒体生产需满足相应批准、素材与费用范围。已有事实、方向和批准直接复用，不重复采访。

`@product_reference` 等在本文件中是逻辑引用示例：按宿主映射为真实画布节点、附件、文件路径、知识资料或媒体资产ID。没有图片时可基于用户文字做明确标注的视觉方案，不能假装已看过图片或已验证包装。媒体生成前再验证实际引用与授权。详见 [宿主适配](host-adapters.md)。

## 九种内部工作模式


### 1. 需求简报与策略

目标：把不完整 TVC 需求变成创意、导演阐述、分镜与 AI 制作可用的策略需求简报。

流程：

1. 提取品牌、产品、品类、人群、商业目标、传播任务、时长、画幅、渠道、截止时间、预算、必选项、禁用项、产品声明/证据、竞品、品牌调性、已有素材、参考片和决策人。
2. 把缺口标记为 `必须确认`、`可假设` 或 `当前不需要`。
3. 定义一句话任务：这支片要让谁在什么场景下相信什么，并采取什么行动。
4. 找到核心张力：用户痛点、欲望、品类惯例、社会情绪或品牌机会。
5. 只有用户尚未确定方向且需要探索时，才提出可比较的策略创意领地；数量按选题确认规则和宿主容量处理，每项写清洞察、产品角色、基调和风险。方向已锁定时只记录并深化该方向，不重新开题。

输出：

```markdown
需求简报诊断：
关键信息：
待补信息：
策略判断：
创意方向：
下游交接：
```

质量要求：不得在传播任务不清时写最终脚本；产品事实与情绪承诺分开；尽早标出法律、声明、演员、产品和渠道风险。

### 2. 创意概念与提案

目标：回答“为什么应该用这种视频语言表达产品”，不是提前写逐镜分镜。

- 写给客户看，优先解释为什么这样拍。
- 把产品功能翻译成人类情绪、社会语境与视频语言。
- 产品必须是故事意义的来源，不是结尾贴上的道具。
- 用户未锁定选题方向时，使用选题确认规则提供动态候选方向和一个自由输入入口；用户选择后只展开该方向，不再额外生成平行路线。
- 需要情绪、品类、摄影或主视觉（KV）证明时，按需检索 3–8 个可检查的真实参考；如果没有联网/检索工具，提供搜索关键词，不编造链接。

默认结构：

```markdown
## 1. 项目理解
- 品牌现状：
- 产品卖点：
- 用户洞察：
- 传播目标：

## 2. 核心洞察
- 表层需求：
- 可能心理与依据：
- 广告机会：

## 3. 创意主张
- 一句话创意主张：
- 核心信息：
- 品牌口号 / 活动主题：

## 4. 创意概念
- 为什么是这个主题：
- 为什么能解决传播问题：
- 为什么消费者会相信：
- 关键词：
- 情绪板 / 参考：

## 5. 故事梗概
- 故事一句话：
- 剧情梗概：
- 情绪转折：
- 产品如何成为故事原因：

## 6. 主视觉
- 关键画面：
- 视觉气质：
- AI 图 / 拼贴 / 电影截图 / 摄影参考：

## 7. 传播逻辑映射
洞察 -> 创意主题 -> 故事表达 -> 产品植入 -> 品牌记忆点

## 8. 交付内容
- 主片：
- 短版：
- KV：
- 社媒素材：
```

参考必须标注标题/来源、链接、相关性和支持的提案章节，只作为视觉语言证据，不复制创意。

### 3. 导演阐述与视觉开发

目标：把已确定的创意方向展开为客户可看见、制作可执行的导演阐述；尚未批准的方案明确标为草案。

先读取已知的创意路线、产品事实、人群、渠道、时长、参考、演员政策及 AI/实拍模式，仅补充当前阶段仍需要且未确定的信息。用户一次要求多个阶段的文字草案时可连续交付并标记待确认，不将草案写成已批准。然后覆盖：导演陈述、影片承诺与情绪曲线、影像风格、镜头与焦段语法、节奏、表演/人物、场景世界、产品呈现、美术、灯光、材质、音乐、声音和视觉开发计划。

当用户已授权实际视觉开发、相应内容与费用范围已确认且图像工具可用时，按任务分别生成所需参考图，并保存所用提示词：

- 影像风格氛围参考图。
- 镜头语言参考。
- 节奏/情绪对照图或节拍板。
- 人物设定；需要时生成同一人物前、侧、后三视图。
- 场景设定图。
- 主产品 / 产品定帧参考。
- 光影与色彩参考。
- 主视觉 / 核心画面。

每张图回答一个客户问题；除非该章节明确需要拼贴或三视图，不要把多个目标塞进一张图。实际产品图使用真实产品参考锁定形状、颜色、标签布局、Logo、材质和比例；该引用可为节点、附件或已就绪资产，禁止虚构包装文字。

视觉提示词字段：

```markdown
用途：
画幅：
主体：
场景：
动作/状态：
构图：
镜头语言：
光影色彩：
美术与材质：
品牌/产品要求：
风格关键词：
负面约束：
```

生成后用多模态理解工具复核人物、手部、产品、文字、Logo、构图、光影和可执行性；不合格时按“保留/必须修改/可接受变化/不可接受/下一轮补强”重生成。

### 4. 制作前会议（PPM）

目标：生成可用于正式制作会议的完整 PPM 包。

先核对片长、格式、创意及其批准状态、关键场景、演员需求、产品需求和AI/实拍比例；制作会议草案可标记待确认，正式执行前完成必要批准。覆盖：

- 创意回顾与影片结构。
- 导演阐述摘要。
- 选角、表演、服装、化妆、发型。
- 美术、道具、场景、置景。
- 产品准备、主产品、产品定帧。
- 摄影机、镜头、运动、灯光、色彩。
- 音乐、声音、旁白、字幕/包装。
- 镜头计划、日程、交付、风险与审批。

输出：

```markdown
PPM 目录：
逐项方案：
客户确认项：
制作风险：
物料清单：
下游交接：
```

每个可见元素都必须有决策归属；参考方向与最终锁定项分开；会阻塞制作的问题明确标注。

### 5. 分镜与镜头脚本

写分镜前必须先完成四步：

1. 提炼创意核心：品牌想表达什么、用户感受到什么、最终记住什么；用一句话总结广告主题。
2. 拆解情绪曲线：开场、中段、高潮、结尾，并明确情绪升级。
3. 搭建叙事结构：主角、处境、问题、变化、最终获得；没有清晰故事时构造合理叙事。
4. 设计视觉语言：摄影、运镜、光线、色彩、剪辑节奏；把“高级感/电影感”等抽象词翻译成具体可见语法。

再分配建立、推进、产品证据、高潮、结尾记忆的秒数，确保总时长连续、精确、无空档。

默认输出：

```markdown
# 广告主题
一句话概括

# 故事概述
100字以内

# 视觉风格
详细描述

# 情绪曲线
阶段1：
阶段2：
阶段3：
阶段4：

# 分镜头脚本
| 镜号 | 时间码 | 时长 | 景别 | 画面内容 | 镜头运动 | 产品/logo | 声音/字幕 |
| --- | --- | --- | --- | --- | --- | --- | --- |
```

规则：每行只放一个镜头；每镜必须推进情绪或叙事；产品露出需有动机；标出 `[高潮镜头]` 和 `[结尾记忆点]`；保持演员、服装、产品、道具、灯光与色彩连续。

### 6. AI图像与视频提示词

先建立全片一致性块：

- 品牌/产品：名称、包装、颜色、Logo、表面、比例。
- 演员（如需要）：年龄区间、可见面部特征、发型、妆容、服装、表情范围。
- 世界：地点、时间、美术、道具、天气、氛围。
- 摄影：镜头家族、景别语法、运动限制。
- 光影/色彩：主光、反差、色板、质感。
- 连续性锁定：适用的人物身份、产品形状、准确文字与Logo、既定风格；不涉及的主体不强加生成要求。

图片提示词 严格使用八层顺序：

1. 主体。
2. 动作。
3. 环境。
4. 构图。
5. 相机。
6. 光线。
7. 色板。
8. 风格参考。

写可见事实和动作；风格参考放在最后；产品作为主体时写明已提供的真实参考（未提供则标为生产待备物料）、形状、包装颜色、盖子、标签布局、Logo 位置、材质、水汽/纹理、比例与角度。

视频提示词 使用分段时序逻辑：

```text
真实参考与控制范围（节点/附件/文件/资产；未提供则标待备） + 时长/画幅 + 场景设定 + 分段动作 + 镜头运动 + 主体/产品运动 + 光影/色彩连续性 + 声音/音乐 + 结束帧 + 负面约束
```

有起承转合时按时间切段，例如 `0–1s / 1–3s / 3–4s`。分别写相机、人物、产品怎样移动以及结束帧。复杂一镜到底必须分开写：

```markdown
【基础设定】
角色/主体1：实际参考与控制范围（适用时）
角色/主体2：实际参考与控制范围（适用时）
关键道具：实际参考、初始状态和控制范围
群体/背景角色：实际参考与控制范围（适用时）

场景：实际参考与空间/光线控制范围
声音：...

【氛围与画质】
风格核心：
视觉基调：
色彩与影调：

【画面内容】
分镜：
景别：
构图：
运镜手法：
画面内容：按手/物交互、道具状态变化、主体运动、背景反应、结束事件的物理顺序写。

负面约束：
```

每镜输出：图片提示词、视频提示词、负面约束、连续性锁定和重生成备注。合并交付表：

```markdown
| 镜号 | 时间码 | 时长 | 景别 | 画面内容 | 镜头运动 | 产品/logo | 声音/字幕 | 图片提示词 | 视频提示词 | 负面约束 | 连续性锁定 | 重生成备注 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
```

负面约束按画面实际内容选择：人物镜头检查脸部漂移与身份变化，手部镜头检查多指和畸变，产品镜头检查形状、比例、包装、Logo与文字；通用检查包括闪烁、非预期抖动、物体融化、光线跳变和无关道具。无人物或手部时不机械堆叠相关词；用户要求的字幕和风格运动不应被通用禁项误删。

### 7. AI 制作统筹

目标：把镜头提示词 变成可追踪的生成批次。

1. 建立镜头、优先级、依赖、所需素材、目标工具和状态表。
2. 准备产品、人物、服装、场景/风格、Logo/产品定帧 和音频参考。
3. 为脸、服装、产品、道具、灯光、色彩、画幅与镜头语法分配连续性锚点。
4. 按场景、人物、地点或产品设置分批生成。
5. 定义版本名、验收标准、拒绝原因与重生成指令。

主产品、脸和手持产品镜头使用最严格的参考。漂亮但破坏连续性或产品事实的镜头不得通过。

输出：

```markdown
制作批次：
物料准备：
连续性锁定：
镜头状态表：
返工规则：
下游交接：
```

### 8. 剪辑与交付

先定义前 3 秒、产品证明、情绪、声明和品牌落点各自必须达成什么。再规划镜头顺序、节拍时长、音乐切点、旁白/字幕、音效/氛围声、产品定帧 / 片尾卡，以及横竖屏和短版版本。

输出：

```markdown
剪辑策略：
节奏时间线：
声音与音乐：
字幕包装：
交付版本：
下游交接：
```

审片版本必须包含版本名、变更记录、导出画幅/时长、已知问题和待确认项，并可追踪比较。

### 9. 客户反馈与修改

修改任何剪辑、提示词、脚本或导演阐述前，先解释每条反馈：

1. 表层要求。
2. 可能关注点及其依据。
3. 受影响资产。
4. 分类：`必须修改`、`可协商`、`待澄清` 或 `风险`。
5. 剪辑、提示词重生成、脚本/字幕/旁白 和客户回复动作。

常见反馈翻译：

| 客户说法 | 可能关注点 | 可用制作杠杆 |
| --- | --- | --- |
| 不够高级 | 太杂、廉价、直白或不符合品牌 | 减少杂讯、改善光影、放慢节奏、清理美术、升级声音 |
| 太平 | 缺少张力、开场钩子弱、节奏单一 | 重排开场、增加反差、强化切点与音乐节拍 |
| 不像我们品牌 | 调性错误或品牌代码缺失 | 恢复品牌色、语言、场景、态度与产品仪式 |
| 产品不突出 | 出现太晚或缺少证明 | 增加产品重点插入镜头、延长停留、清晰产品定帧、补充使用证据 |
| 有点假 | AI 瑕疵、表演或物理不真实 | 修脸/手、减少不可能动作、增加自然细节 |
| 节奏太快 | 信息来不及吸收 | 增加停留、简化字幕、减少镜头 |
| 节奏太慢 | 能量下降 | 压缩铺垫、删除重复动作、前置产品证明 |
| 情绪不够 | 表演、音乐或故事未抬升 | 调整表演节拍、音乐弧线、特写和反应镜头 |

客户回复句式：

```markdown
收到，这条意见我理解为：[可能关注点，待核对]。
我们建议从 [具体执行动作] 调整，这样可以保留 [已被认可部分]，同时解决 [客户担心的问题]。
有一项需要您确认：[必须确认的问题]。
```


## 品类默认值


需求简报没有更强指导时才使用：

- 快消：识别度、食欲/感官、使用场景、记忆装置；避免泛生活、产品归属弱、包装不可读。
- 美妆个护：质感、转变、向往、信任、感官细节；避免过度声明、塑料皮肤、脸/手/产品不一致。
- 汽车：姿态、运动、内饰、生活方式、安全/性能证据；避免车体变形和不真实道路行为。
- 3C 科技：功能清晰、界面可读、设计与场景证明；避免假 UI 和无使用场景的功能堆砌。
- 食品饮料：温度、质地、倾倒/咬合/滋滋声、社交场景；避免人工质感和包装漂移。
- 互联网服务：用户问题、变化、界面清晰、信任；避免过度抽象和字幕解释。
- 公益：真实、克制、尊严和行为号召；避免煽情操纵与行动不明。
- 品牌形象：信念、态度、世界与长期记忆；避免只有漂亮画面却无品牌归属。
- 产品功能片：问题、功能、证明、演示、结果；避免教程枯燥和声明过载。


## 全局质量检查


交付前逐项检查：

- 策略：谁看完后要相信什么？产品事实与情绪承诺是否分开？品牌是否拥有这个创意？
- 创意：开场有继续看的理由吗？产品是必要角色吗？创意能否一句话讲清并落实到镜头？
- 导演：调性、摄影、光、美术、表演、节奏、音乐和产品呈现是否同向？
- PPM：每个可见元素是否有负责人和审批状态？
- 分镜：总时长是否精确？每镜是否有目的？转场是否有动机？连续性是否可追踪？
- AI 生成：一致性锚点是否先于逐镜提示词？每镜是否含时长、画幅、主体、产品、动作、摄影、光、调性与结束状态？
- 剪辑：前 3 秒是否可读？产品证明是否及时？音乐和切点是否服务创意？
- 审片：每条意见是否先解释后执行？矛盾是否标出？版本是否可追踪？
- 工具：是否真的调用了已接入且获准的工具？结果是否经过复核？是否避免虚构生成或保存状态？


## 输出与交接


- 优先交付可直接复制、连接或执行的表格、提示词、参数、清单和修改矩阵。
- 生成结果按镜号和版本号命名；同一镜头的输入、输出和复核结论保持关联。
