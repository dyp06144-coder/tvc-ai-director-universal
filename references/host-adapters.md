# 宿主与工具适配

## 运行模式

按当前真实能力决定执行范围，不按模型或产品名称推定能力：

| 模式 | 所需能力 | 可交付 |
|---|---|---|
| 纯聊天 | 当前上下文与文本输出 | 需求诊断、创意、导演阐述、PPM、分镜、提示词、审片建议和会话交接 |
| 文件/知识库 | 实际资料读取、可选文件保存 | 读取参考，输出完整制作资料包、表格、版本与交接记录 |
| 部分制作 | 可用图像、音频或视频工具中的一部分 | 已授权且能执行的实际媒体，以及未完成部分的明确清单 |
| 完整制作 | 对应媒体来源、生成/实拍素材、检查、剪辑、播放、导出 | 经检查的成片及实际存在的工程、字幕与交付文件 |

具备文本能力不表示能生成视频，具备视频模型不表示能剪辑导出。没有画布、原生卡片、电子表格或某一品牌模型，不应阻断可完成的文字范围。只做方案时不要求用户先接入生产工具；进入实际生产时检查其真实依赖。

技能不能提供网络、凭据、服务配额、后台调度或宿主未暴露的API。只使用当前已接入且获准的能力；不自动安装工具、不强迫换宿主，不把计划、提示词或空节点称为真实媒体。

## 输入与引用责任

下表别名为逻辑标签，不是所有宿主必须使用的节点语法：

| 输入 | 逻辑标签 | 控制范围 |
|---|---|---|
| 项目需求 | `brief` | 目标、受众、渠道、时长、预算与交付 |
| 品牌规范 | `brand_guide` | 品牌色、语气、Logo、必需与禁用项 |
| 产品主参考 | `product_reference` | 可见包装、形状、颜色、Logo、材质与比例 |
| 人物参考 | `character_reference` | 人物身份、发型、妆容、服装、身体比例 |
| 服装参考 | `wardrobe_reference` | 版型、面料、配色及饰品 |
| 场景参考 | `scene_reference` | 空间、布景、时间、天气与道具 |
| 风格参考 | `style_reference` | 影调、摄影、光色与材质，不复制人物/品牌 |
| 参考片/粗剪 | `video_reference` | 已看过的镜头、运动、节奏或待审内容 |
| 声音参考 | `audio_reference` | 音乐、旁白、同期声、节奏或声音身份，分别标明角色 |
| 客户反馈 | `client_feedback` | 未预先改写的真实反馈 |

每项保存来源类型、真实位置/句柄、版本、状态及控制范围。同类可编号；不能把角色名字或逻辑标签填进要求实际媒体ID的接口。包装外观的图片依据与产品功能的书面证据分别登记，不能从照片推断不可见功效。

### 画布

存在画布时可保留 `@product_reference` 等真实引用，将Agent实际连接的组件映射到相应能力；按宿主支持的方式连接预览和保存。空节点创建、生成请求接受、媒体完成与检查通过是不同状态。

### 文件、附件与API

把标签映射为可读附件、文件、知识库条目、真实URL或注册资产ID。先确认当前工具可读取，说明它控制什么，再按实际schema传参。提示词中的文字别名不是已经完成上传；没有读图能力时不能声称已看图。

素材尚未提供但用户只要草案时，可使用已明确的文字事实与标注设计假设，不虚构参考；将未来生产需要的真实产品图、Logo、角色或声音列为待备物料。若用户要求精确还原包装但既无清晰参考也无准确规格，只能列缺口或做明确非最终示意，不能宣称还原成功。

### 纯聊天与知识库不可读

只在聊天中输出完整内容，不拼造本地路径或下载地址。参考文档无法读取时，说明未读取，依据已提供信息交付可做部分；必要的精确品牌或产品信息仍需补充。不要假装整个资料库已加载。

## 工具合同

为真正可用的工具记录：用途、必填输入、可选控制、当前限制、输出类型、异步状态、检查方法与费用范围。以下是需要核对的逻辑内容，不是通用函数名或固定JSON键：

- **文本/表格**：可读取资料与输出长度、表格列数、保存/读回能力。没有工作簿工具时用Markdown/TSV；不能把TSV冒称XLSX文件。
- **图像生成**：提示词、产品/人物等真实参考、比例/分辨率及支持的质量设置。输出真实图片后检查人物、手、包装、Logo、文字、构图、光色与可执行性。
- **图像编辑**：实际原图、需要时的遮罩、要修改和保留区域；区分生成、局部编辑与排版合成。
- **视频生成**：实际支持的文生/图生/参考/首尾帧/延长模式、时长、比例、参考数量、声音能力和任务状态。复杂动作按当前控制力拆解，不假定每个服务都接受相同时间段格式。
- **音频/语音**：文本、真实声音ID或获准录音、语种、时长及支持的参考范围。人物图片不自动成为TTS输入；不能把配乐当声音身份，也不能从照片推断声音克隆许可。
- **多模态检查**：确实可读取的图片/视频/音频、检查目标和证据；先说可观察事实，再区分主观判断与不可检事项。
- **图像合成**：真实图片、文字、尺寸、图层/布局；不能用合成伪造产品声明或改掉已批准Logo。
- **剪辑/导出**：实际素材、时间线、音轨、字幕/包装、预览、输出格式与真实路径；原生编辑器、已获准本地工具或API均可，保留现有工程和用户修改。

参数名、模型ID、枚举和限制以运行时描述与实际结果为准。原模板中的 `prompt`、`aspect_ratio`、`reference_media` 等只能作为概念示例，不能原样假定每个工具都有这些字段。

## 宿主专属限制

目录名、文件类型、单文件大小和导入数量限制只作用于对应平台，不能扩展为所有Agent通用限制。导入前读取当前宿主要求；本包默认使用Markdown、YAML与JSON，入口固定为 `SKILL.md`。不能识别某个可选配置的宿主可以忽略它，通用工作规则仍在主入口和参考中。
